# FLUX WebGL Fluid Landing Page

架空AI企業「株式会社フラックス」のコーポレートサイト風サンプルです。  
生成りの紙、墨流し、瑠璃と朱の差し色をテーマにした静的なランディングページで、背景に WebGL の流体シミュレーションを使っています。

> このサイト内の会社名、ニュース、実績、所在地、メールアドレスなどはすべてサンプル用のダミーデータです。実在の企業・団体とは関係ありません。

## 特徴

- HTML / CSS / JavaScript だけで動く静的サイト
- WebGL 流体シミュレーションによるインタラクティブな背景演出
- スクロールに応じたヘッダー変化、フェードイン表示、数値カウントアップ
- PC / スマートフォン対応のレスポンシブレイアウト
- モバイル用ナビゲーションメニュー
- `prefers-reduced-motion` に配慮したモーション低減

## ファイル構成

```text
.
├── index.html       # ページ本体
├── css/
│   └── style.css    # レイアウト、配色、レスポンシブ設定
└── js/
    ├── fluid.js     # WebGL 流体シミュレーション背景
    └── main.js      # UI制御、スクロール演出、メニュー制御
```

## 使い方

ビルド作業は不要です。ブラウザで `index.html` を開くと表示できます。

ローカルサーバーで確認する場合は、プロジェクトのルートで次のコマンドを実行してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで次のURLを開きます。

```text
http://localhost:8000
```

## カスタマイズ

主に次のファイルを編集します。

- 文章、セクション、リンク先を変更する: `index.html`
- 色、余白、フォント、レスポンシブ表示を変更する: `css/style.css`
- スクロール演出、メニュー、カウントアップを変更する: `js/main.js`
- 背景の流体表現、色、強さ、解像度を変更する: `js/fluid.js`

配色は `css/style.css` の `:root` にまとめています。

```css
:root {
  --paper: #f7f5f0;
  --ink: #1f1f24;
  --ruri: #1e50a2;
  --shu: #b3361e;
}
```

## 配布前の注意

- ダミーの会社情報、ニュース、採用情報、メールアドレスを必要に応じて差し替えてください。
- Google Fonts を外部CDNから読み込んでいます。オフライン配布する場合はフォントの扱いを別途調整してください。
- WebGL を利用しているため、古いブラウザや一部端末では背景演出が正しく動かない場合があります。
- `js/fluid.js` は MIT ライセンスの WebGL Fluid Simulation を改変して使用しています。再配布時はライセンス表記を残してください。

## 第三者コード

背景の流体シミュレーションは、Pavel Dobryakov 氏の [WebGL Fluid Simulation](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation) をベースに、このサイト向けに調整しています。

オリジナルコードは MIT ライセンスです。ライセンス文は `js/fluid.js` の冒頭に含まれています。
